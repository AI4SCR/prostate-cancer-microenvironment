# Figure → script mapping

Which script produces each panel of each main-text figure. Blank "Script" = not implemented in this repo yet; "—" = not code-derived / no source found. "Validated" = output visually confirmed to match the published panel. "Ported from" = the legacy repo file(s) this script is a 1:1 port of (paths relative to `PCa/`) -- for rows with no `Script` yet, this is our best-guess candidate source (see `open-questions.md` for confidence/caveats), not a confirmed port.

**Source-selection policy**: `000_paper/sync_paper/` holds collaborators' later edits (confirmed via git history -- every `sync_paper` file checked has a later last-commit date than its `000_paper/11_niches/`(or other legacy-dir) counterpart). `Ported from` always cites the `sync_paper` sibling when one exists, and the script is a verbatim port of it -- **including when that source is itself broken**, per explicit user instruction: reproducing the actual script the paper's collaborators used takes priority over having a working script, so a broken source is ported verbatim (see Figure 6d/7a below, both `BLOCKED`) and documented for upstream fixing, not silently swapped for an older script that happens to run. The older legacy-dir path is cited only when no `sync_paper` sibling exists at all. Rows 6b, 6e, 7b, 7c, S6bc were blocked on missing input data (`cell_annotation.parquet`) until 2026-08-05, when Melissa supplied it (see `bugs.md`); all five now run end-to-end. Row 6a was blocked on the same missing-data issue plus several `yaml`/`ComplexHeatmap` bugs, all now fixed -- every row in this table is either implemented-and-working or `not implemented` for a non-code-derived/no-source reason (Fig 1a-c, 3c-e, 5c, 7g-h, S4a, S5a) as of 2026-08-05.
